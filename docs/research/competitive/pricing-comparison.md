## What riders clearly expect to be free

1. Basic route planning
2. GPX import/export
3. Basic navigation (turn-by-turn)
4. Ride recording
5. Map viewing
6. POI search

## What riders plausibly would pay for

1. Offline maps + routing (DMD proves this — free core + paid online layers)
2. Advanced route discovery (AI builds, Free Ride)
3. Premium map layers (topo, satellite, traffic)
4. Community features (groups, sharing, leaderboards)
5. Safety features (crash detection, SOS)
6. Hardware integration (OBD, TPMS, remotes)

## Open-source/self-hosted model

OpenGravel can offer:
- Free core routing + discovery (open data, open source)
- Self-hosted instance for privacy-conscious riders
- Optional premium for advanced features (weather, traffic, proprietary data)
- No subscription trap — open-source core never paywalled

This is unique in the motorcycle navigation space. No competitor offers a self-hosted option.

## Pricing implications for OpenGravel

1. **Free tier must include:** planning, routing, Free Ride, GPX workflow, basic navigation.
2. **Premium could include:** weather, traffic, offline packs, advanced Free Ride, API access.
3. **Self-hosted:** free, no premium — the whole point is open.
4. **No lifetime trap:** subscriptions should be cancellable anytime with full export.
5. **Transparent pricing:** show what's included, not what's locked.
