## Key findings so far

- Switchback Moto treats roads as persistent content entities (Atlas, badges, trophy case) — unique approach.
- DMD² is a hardware+software cockpit, not just an app — remote controllers, OBD, TPMS, LoRa.
- GoraAdv's T1–T5 explicit surface hierarchy is structurally better than binary avoid/unpaved.
- Trails Offroad invests heavily in curated trail guides + obstacle documentation — a model for road-condition layers.
- Calimoto's central weakness: surfaces treated as binary, no confidence model, stale closure data.
- Kurviger strong in Europe, weak elsewhere; no mixed-surface intent.
- REVER: social is strongest feature, routing is middling, stability problems reported.
- Scenic: iOS-first, strong offline, detour controls, but no mixed-surface intent.
- Cardo Ride: hardware ecosystem advantage (intercoms), software still maturing.
- Offroad Pilot: free, seeks unpaved by default, Netherlands-only web app.
