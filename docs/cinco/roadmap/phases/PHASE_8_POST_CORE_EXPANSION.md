# Phase 8 — Post-Core Expansion

This phase is intentionally **not part of the core CINCO alignment release**.

Only begin after Phases 0–7 have strong UX and reliability evidence.

## Candidate workstreams

### Group rides / live location
Potential:
- temporary ride groups,
- live rider location,
- privacy-first session sharing,
- regroup points.

### Curated community roads
Prefer structured road intelligence over a generic social feed:
- route/road comments,
- temporary closures,
- gravel/surface reports,
- scenic notes,
- rider photos,
- confidence/freshness.

### Ridden-road history
Heatmap / novelty:
- roads ridden recently,
- roads never ridden,
- avoid repetition,
- rediscovery.

### Automotive surfaces
CarPlay / Android Auto require a native/automotive strategy.
Do not treat them as “just responsive web.”

### Rich ride replay
Potential:
- route vs actual,
- elevation,
- speed,
- route quality,
- Free Ride decisions,
- photos/notes.

## Do not prioritize
- gamification badges for their own sake;
- generic feed engagement loops;
- AI summaries without user value;
- 3D avatars;
- broad nationwide live-condition ingestion before regional quality is proven.
