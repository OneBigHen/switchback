# Screen-by-Screen Requirements

## Screen A — Phone Home / Map

### Visible without interaction
- search pill;
- map;
- locate / map-style control cluster;
- compact context sheet;
- primary shortcuts: Free Ride / Round Trip / Destination;
- recent ride/route if available;
- bottom navigation when not immersive.

### Hidden until expanded
- full route preferences;
- libraries;
- detailed layers;
- bike profile details;
- scoring controls.

## Screen B — Selected Route / Peek

Visible:
- route identity,
- Best/Twisty/Flowy/Scenic label,
- time,
- distance,
- elevation,
- short rider-character line,
- Go / Navigate.

One expansion:
- reasons,
- surface,
- curves/flow,
- towns/traffic controls,
- comparison.

## Screen C — Alternatives / Half

Phone:
- 2–4 route cards stacked.
- map remains visible above/behind.
- selected card is unmistakable.
- card selection updates map immediately.

Tablet:
- left panel may list routes,
- map shows alternatives,
- right detail inspector optional.

## Screen D — Route Detail / Full

Sections:
- overview,
- road character,
- elevation,
- surface,
- live conditions,
- stops/fuel,
- advanced/data quality.

Collapse sections rather than endless card nesting.

## Screen E — Route Editing

Expose:
- start,
- destination,
- stops,
- shaping points,
- road/corridor locks,
- profile,
- avoid settings.

Map gestures and list editing stay synchronized.

## Screen F — Free Ride Setup

Keep compact.
Primary:
- Start Free Ride
- Surprise me/default profile
Secondary:
- Curves
- Scenery
- Flow
- Gravel
- max detour

Recent Free Ride routes can appear below.

## Screen G — Free Ride Moving

Visible:
- map,
- basic ride telemetry,
- no suggestion OR one compact suggestion,
- pause/exit where safe.

Suggestion:
- opportunity,
- distance,
- added time,
- 1–2 traits,
- Take / Pass.

## Screen H — Active Navigation

Top:
- maneuver / distance / next.

Center:
- map.

Bottom:
- speed,
- limit,
- ETA/remaining/arrival.

Secondary actions hidden behind one control.

## Screen I — Add Stop During Ride

Must preserve visible navigation context.
Results show:
- stop name,
- category,
- added minutes,
- added miles,
- route-side appropriateness.

## Screen J — Tablet Landscape Planner

Left ~384 px:
- search,
- route mode,
- route list / route detail.

Center:
- 3D map.

Right temporary:
- selected road/place/condition inspector.

Do not create three permanent dense columns if map becomes unusable.

## Screen K — Tablet Portrait

Use side rail or anchored sheet.
Map stays visible.
Route editor uses vertical room without consuming entire screen.

## Screen L — Layer Control

Taxonomy:

### Road Character
- Curvature
- Unpaved / surface
- Favorite / known roads
- Road locks
- ridden history (future)

### Conditions
- Live incidents
- Closures
- Construction
- Winter roads
- Weather

### Discovery
- Fuel
- Food
- Scenic overlooks
- Repair
- Camping/lodging

### Map
- CINCO
- Satellite
- Night
- 2D/3D
- detail tier

No single flat 20-item checklist.
