## Key Decisions Made

| Decision | Rationale | Alternatives Considered |
|----------|-----------|------------------------|
| Preserve incoming work on a dedicated reconciliation branch | User work and the sampled prototype remain reviewable without pretending the sparse graph is regional routing | Discarding the dirty tree or folding prototypes into one commit |
| Build regional data directly from normalized OSM PBF | Sampled GraphHopper responses cannot establish full regional coverage, legality, or provenance | Retaining the 6x6 sampled graph as a regional pack |
| Use content-addressed `gzip-json` spatial tiles | Browser `DecompressionStream('gzip')` is portable, and serving `.json.gz` as `application/gzip` preserves compressed-byte checksums | Zstd through HTTP `Content-Encoding`, which can be transparently decoded and invalidate checksum semantics |
| Treat unsupported conditional access conservatively | Offline routing must not silently authorize roads whose conditions cannot be evaluated | Assuming conditional roads are open |
| Keep regional v1 bundles as update-required | Prevents sparse or incompatible data from being silently parsed as full v2 coverage | Automatic best-effort v1 regional parsing |
| Keep UI shell state typed and routing data in existing stores | Avoids duplicating route state while providing real Plan/Library/Record/Profile destinations and overlay history | Adding more unrelated local state to `PlannerShell` |
| Block service workers in Playwright | Production PWA interception bypassed Playwright route fixtures and caused order/viewport-dependent API behavior | Treating mocked-request failures as product routing failures |
| Scope road-lock positioning under `.planner-shell` | Component CSS was emitted after the global skin and won equal-specificity rules, physically covering Layers | Test-only forced clicks or moving the tool without fixing the cascade |
