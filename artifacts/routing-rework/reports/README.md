# Routing Rework Benchmark Reports

Tracked, sanitized summaries for the routing-intelligence rework. Raw per-request
samples live in `../raw/` and are gitignored; only sanitized tables and contract
snapshots belong in this directory.

## Baseline schema

Each report is generated by `scripts/benchmark-routing.mjs` and contains:

- Generation metadata (timestamp, base URL, run count, warm/cold tag).
- Health state of app, router, and optional Valhalla (never fatal; recorded as
  unreachable when a service is down).
- The golden intent contract for the exact prompt
  `2 hour fun ride from Hatboro to Stockton NJ` — `mode`, `profile`,
  `targetMinutes`, `destinationQuery` — captured from the live boundary.
- Per-endpoint p50/p95/max wall-clock timings across runs for:
  - `intent.golden` — `/api/ride-intent`
  - `routes.direct` — `/api/routes` (single profile, no compare)
  - `routes.compare` — `/api/routes` with `compare: true`
  - `routes.loop` — `/api/routes` native round trip (120 min, seed 17)
  - `routes.long` — `/api/routes` scenic Harrisburg → Scranton compare
- Observed provider counts per endpoint (`graphhopper`/`valhalla` per returned route).

## Policy

- No credentials, prompts, or personal data are ever written here.
- Thresholds are **not** enforced by Phase 1; the performance budget gates live
  in Phase 7.
- Regenerate with `npm run benchmark:routing [-- --runs N]`.
