# Agent Work Log Template

Create `docs/recovery/WORKLOG.md`.

## Entry

### YYYY-MM-DD — Phase/task

**Goal**  
What changes and why.

**Repository evidence**  
Files, tests, traces, runtime behavior.

**Decision**  
Chosen design and rejected alternatives.

**Changes**  
Files, behavior, migrations, UI impact.

**Verification**  
Commands and outcomes.

**Remaining risk**  
Device-only checks, provider dependency, uncertainty, or deferred work.

**Commit**  
SHA and message.

## Phase summary

Record completed issue IDs, architecture changes, migrations, tests, known degradations, evidence, and next-phase entry conditions.
